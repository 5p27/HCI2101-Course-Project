4. Course General Description

This course focuses on the principles and techniques of designing effective data visualizations within the context of Human-Computer Interaction (HCI). Students will learn how to represent complex data in intuitive, interactive, and aesthetically pleasing ways. Key topics include visual perception, cognition, storytelling with data, and the use of modern visualization tools to support user tasks and decision-making.
