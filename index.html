4. General Course Description:
This course focuses on the principles and techniques for designing effective data visualizations within the context of Human-Computer Interaction (HCI). Students will learn how to represent complex data in intuitive, interactive ways, leveraging design principles, cognitive psychology, and visualization tools. Topics include visual perception, data storytelling, and creating user-centered visual interfaces to support decision-making and enhance user experience.

5. Pre-requisites:
HCI2203 - User Research
DS2201 - Introduction to Databases

6. Co-requisites: None

7. Main Course Objective:

  • Understand and apply foundational principles of data visualization, including visual perception and cognitive psychology.
  • Design and implement user-centered data visualizations that are intuitive, accessible, and engaging.
  • Utilize modern tools and technologies to create interactive, dynamic visual representations of complex datasets.
  • Critically evaluate the effectiveness and ethical considerations of visualizations in diverse contexts.
