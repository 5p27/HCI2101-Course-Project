Course Specification

Course Title: Data Visualization Design

Course Code: HCI 3401

A. General Information About the Course

1. Credit Hours: (4) Hours (3 Lecture + 2 Lab)

2. Course Type: Required (Department Requirement)

3. Level/Year: 3rd Year / 5th Level

4. Pre-requisites: User Research (HCI 2203) and Database (DS 2201)


Course General Description:

This course focuses on the principles and techniques of designing effective data visualizations within the context of Human-Computer Interaction (HCI). It covers visual perception, information theory, storytelling with data, and creating user-centered visual interfaces for complex datasets using modern visualization tools.

B. Course Learning Outcomes (CLOs)

Code Course Learning Outcomes Teaching Strategy Assessment Method
