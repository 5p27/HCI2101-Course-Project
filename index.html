4. Course General Description:
This course focuses on the principles and techniques of designing effective data visualizations within the context of Human-Computer Interaction (HCI). Students will learn how to represent complex data in intuitive and interactive ways, leveraging design principles, cognitive psychology, and visualization tools.

5. Pre-requirements: HCI2203 - User Research, DS2201 - Introduction to Database

6. Co-requisites: None

7. Main Objective(s):

  • Understand foundational principles of visual perception.
  • Design user-centered, accessible visualizations.
  • Utilize modern tools for interactive visual representations.
  • Critically evaluate effectiveness and ethics.
